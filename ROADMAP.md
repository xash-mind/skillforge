# SkillForge Roadmap

Status: charter-review draft

## Milestone 0 — Charter and infrastructure gates

Approve and lock the charter. Select the Supabase organization, confirm project cost, then create exactly one project. Create the single Vercel project only when the first deployable increment is ready.

## Milestone 1 — Reproducible application foundation

Complete TASK-001: Next.js shell, modular boundaries, environment validation, quality gates, testing, and failure-state scaffolding.

## Milestone 2 — Secure tenancy foundation

Complete TASK-002: Supabase schema, Auth, organizations, branches, memberships, role assignments, RLS, and audit.

## Milestone 3 — Academic and class operations

Complete TASK-003 and TASK-004: syllabuses, subjects, classes, timetable, enrollment, attendance, evidence uploads, homework, and the guided teacher lifecycle.

## Milestone 4 — Learning Evidence Engine

Complete TASK-005: ingestion, evidence taxonomy, lineage, syllabus links, and Learning Graph.

## Milestone 5 — Teacher-controlled AI

Complete TASK-006: adapter plug-in contract, multiple adapters, tenant-owned provider configuration, gap drafts, and approval.

## Milestone 6 — Role dashboards

Complete TASK-007: organization, teacher, student, and parent workflows with mobile and accessibility evidence.

## Milestone 7 — Billing and governance

Complete TASK-008: manual billable status, usage snapshots, plans, invoices, regional policy selection, consent, retention, export, and deletion.

## Milestone 8 — Release

Complete TASK-009: full regression, preview verification, owner acceptance, production deployment, canonical URL verification, and rollback evidence.

Phase-2 generation and Phase-3 tutoring remain outside the MVP and require approved change requests after completion.
